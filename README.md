# Turok1 Quicksave

![Turok1 Quicksave](https://raw.githubusercontent.com/VinceCrusty/Turok1_Quicksave/main/turok_quicksave.jpg)

Standalone Quick Save / Quick Load mod for Turok Remastered.

## Features

- Quick Save and Quick Load in the pause menu
- Continue in the main menu
- Timestamped saves
- Player position and orientation restoration
- Boss-state persistence
- Persistent bonus-stage warp return points

## Installation

1. Extract Turok1_Quicksave_v1.0.zip.
2. Copy the included Vulkan DLL to the Turok game folder.
3. Copy the included KPF file to Turok's mods folder.
4. Use the D3D11 DLL instead if your setup uses a compatible D3D11 wrapper.

## Warning

Turok was not originally designed for unrestricted quick saves. Avoid saving during cutscenes, map changes, warp animations, death sequences, boss intro/outro events, or any active scripted sequence. Keep normal save points as a backup.
